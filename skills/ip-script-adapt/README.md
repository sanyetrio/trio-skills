# 参考别人的做法，写自己的口播稿

已有参考作品或拆解，想结合自己的人物资料、真实案例与表达习惯起稿。

| 使用前提供 | 完成后得到 |
|---|---|
| 参考材料、自己的账号方向与真实资料、本次题目；有口吻样本和拍摄条件也一起提供。 | 口播稿、采用与改造说明、分段稿和来源对应表。 |

## 直接这样说

> 用 $ip-script-adapt 结合这份参考拆解和我的资料，写一条口播稿；不要把参考作者的经历写成我的经历。

## 安装与依赖

把本目录作为完整的 `ip-script-adapt` 文件夹，放入你使用的 AI 客户端的技能目录，保留 `SKILL.md` 和所有随附资源；已有同名技能先比较，避免覆盖已有修改。在客户端重新加载技能后，发送上面的示例并附上实际材料。

基础写稿不依赖其他技能或脚本；具体专业事实核验需要可访问的可靠资料。后续分镜可选用其他工具。

## 使用范围

不会编造人物经历、客户结果或引用；缺少的关键事实会留在说明中，不混入口播正文。
