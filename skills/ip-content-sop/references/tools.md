# 可选能力与依赖

本技能包提供工作顺序、文件交接和本地辅助脚本，不包含采集服务、转写服务、视频编辑器、飞书账户或 Obsidian 库。先检查当前环境实际可用的技能和工具；下面的工具名仅作可选入口举例，不假定使用者已安装，不自动安装或连接账户。

| 需要做的事 | 可使用的能力 | 完成证据 |
|---|---|---|
| 单条参考作品采集 | 用户提供的导出文件，或当前已安装且用户指定的采集工具 | 原记录正文、来源与实际状态 |
| 同博主批量采集 | 用户已有 CSV/作品清单；`bozhu-collector` 等仅在实际可用时使用 | 实际作品清单、可观看原片、正文与失败项 |
| 转写、视频制作任务记录 | 已有 SRT/时码 JSON；如安装了 `trio-video-workbench` 或 AI 剪口播，可按其当前文档衔接 | 原任务回执、真实时码文本、可播放文件 |
| 已有定位或访谈 | 用户提供的当前 IP 材料；可选 `IP定位顾问`、`ip-brief` | 本人已确认材料与未知项 |
| 飞书文档 | 当前已连接并授权的文档能力，例如 `lark-doc` | 写后回读的正文、图片与附件 |
| 飞书多维表格 | 当前已连接并授权的多维表格能力，例如 `lark-base` | 目标表、记录 ID 与回读字段 |
| Obsidian 正式归档 | 用户指定 vault 的规则与项目说明；另行安装的 `ip-knowledge-ingest` 可直接生成 Markdown | 原文、拆片、索引可返回来源，写入范围与回执 |
| 图像生成、剪辑、包装或渲染 | 用户指定且当前可用的制作工具 | 实际图片尺寸、时间线、声音和输出检查 |

本套自动分镜由当前 AI 按 Skill 生成分镜文件，本地 Python 脚本辅助校验。它不部署后台模型服务，不自动向其他工作台增加按钮。纯文件排序、状态登记、分镜校验只需要 Python 标准库；证据准备额外需要已安装的 ffmpeg、ffprobe。

没有可用的外部工具时，先处理用户已提供的本地材料并列明缺口。旧说明与当前安装不一致时读取实际入口和 `--help`，不把文档存在当作接入完成；不要为“自动”擅自重装、切网络、换模型、创建后台轮询或重跑未知状态的付费任务。
