准备把脚本与分镜交给拍摄或剪辑，想先发现漏句、缺素材、来源不清和无法执行的安排。

| 使用前提供 | 完成后得到 |
|---|---|
| 当前版本的脚本、分镜、素材清单、拍摄条件，以及必须保留的要求。 | 具体问题与修正位置、待补项、版本化交付清单和本次检查范围。 |

## 直接这样说

> 用 $ip-content-review 检查这份脚本和分镜是否能拍，重点找漏句、缺素材和来源不清的内容，列出具体修改位置。

## 安装与依赖

把本目录作为完整的 `ip-content-review` 文件夹，放入你使用的 AI 客户端的技能目录，保留 `SKILL.md` 和所有随附资源；已有同名技能先比较，避免覆盖已有修改。在客户端重新加载技能后，发送上面的示例并附上实际材料。

基础方案检查只需读取提供的文件，不依赖其他技能；检查真实成片时另外需要当前环境的播放能力。

## 使用范围

没有视频时只核验方案；检查通过不表示本人终审通过、拍摄完成或已经发布。
