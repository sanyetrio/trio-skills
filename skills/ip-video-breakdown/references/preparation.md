# 本地证据准备

## 运行

在本技能目录运行 `python3 scripts/prepare_evidence.py --help`。需要 Python 3.9+、本机 ffmpeg 与 ffprobe。脚本依次检查显式 `--ffmpeg/--ffprobe`、PATH，以及通用安装目录 `/opt/homebrew/bin`、`/usr/local/bin`、`/usr/bin`。其他位置或 Windows 环境可通过 PATH 或显式参数指定；不读取个人工作台目录。显式指定的程序不可执行时直接报告，不静默换用其他程序。找不到就报告，不下载或安装。

```bash
python3 scripts/prepare_evidence.py \
  --source-id R01 --media "/素材/R01.mp4" \
  --transcript "/素材/R01.srt" \
  --out "/项目/evidence/R01" \
  --interval 5 --threshold 0.25 --max-frames 120
```

没有转写时省略 `--transcript`；已有 JSON 接受 `[{'start':秒,'end':秒,'text':'原文'}]` 的标准 JSON 写法（双引号），或 `{"segments":[...]}`。时间单位固定秒，不能把毫秒直接传入。SRT 接受逗号/点毫秒；不能解析、空段或越界时报错，不静默丢句。允许相邻转写时间重叠，保留多人同时发言的可能；最终展示时说明实际情况。

`--extract-audio` 可导出第一音轨的本地 WAV 供听审，不上传。保留原采样率与声道，16-bit PCM 是听审代理文件，不作为原始母带；多音轨会提醒。没有音轨时 `has_audio_stream:false`，不伪造音频文件。

输出目录必须不存在，以免覆盖人工分析。失败会留下 `failure.json` 和部分准备材料；修正输入后使用新输出目录。源片不剪裁、不重命名、不覆盖，前后 SHA-256 一致才输出成功清单。

## 输出与怎么用

| 文件 | 用途 | 不能据此声称 |
|---|---|---|
| `evidence-manifest.json` | 源片指纹、候选切点、每张图的请求时间、已有转写、覆盖空记录 | 已完成拆片、原作者用了某种手法 |
| `frames/*.jpg`、`index.html` | 按顺序看静帧，挑需回看片段 | 运镜、动画、转场或声音已核实 |
| `probe.json` | 时长、轨道、编码信息 | 已听音轨、已看全片 |
| `scene-scan.log` | 候选场景检测记录 | 候选等于全部真实镜头 |
| `audio.wav`（可选） | 供实际播放、听取的声音代理 | 已经听过、适合用于成片 |

## 检測限制

使用既有 ffmpeg 的低分辨率画面差异 `scene` 检测，不依赖新模型。候选包括差异切点、候选段中点及每 5 秒额外采样。超过上限时均匀减少截图，并明确记录原数量与保留数量。阈值改变会影响候选数量，不代表语义准确率。

相似画面硬切、短镜头、叠化、屏幕局部变化、快速运镜都可能漏检或误检；字幕或闪光也可能造成误报。原片从容器播放时间 0 开始计时；有异常起始时间、不同音轨偏移或明显视听错位时先校正时间基准，不把自动截图时间当精确切点。截帧输出最长边受横向 1280 限制，仅作证据预览，非用户最终图示成品。

拆片 agent 必须真实查看图片，并用原片补足关键动态。没有音视频播放能力时交付文字/静帧部分分析，`status: needs_input`，把待观看范围写清楚。

## 与现有工具配合

本脚本只在本地调用 ffmpeg/ffprobe，不包含 ASR 服务、模型调用或账户配置，不读取凭据。已有项目若提供准确切点、转写或截图，应先核对原片指纹并复用；不要求重跑已有流程。转写缺失时使用使用者选定的转写能力，收费操作遵循其明确授权。
