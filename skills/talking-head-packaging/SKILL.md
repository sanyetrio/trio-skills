# 口播视频包装

把现有口播处理为封面与正文风格一致、人物画面自然、字幕清楚且样式统一的可编辑工程；按当前要求输出预览、封面或成片。

## 基础配置

提供视频或已有工程、参考模板、本次处理范围与输出目录。实际执行需要可用的开拍、剪映或用户指定编辑器，以及对应应用控制工具；本技能不附带编辑器、字体、账号、付费额度或私人模板。沿用用户现有工程；应用不可用时说明未执行的步骤。

## 接续素材与风格

1. 确认当前目标视频／工程、账号或人物、现有字幕和参考模板，以及本次只改哪些项目。信息足够就开始；只有素材对象、固定模板或必要交付要求无法判断时才集中询问。
2. 当前要求优先，其次为该账号已确认的模板，再其次为当前工程样式。没有指定应用时沿用现有工程；新任务可从开拍开始。只做局部修改时保留其他设置，不以“包装”为由重剪内容、改语速、剪气口、加配乐或人声美化。
3. 读取已有工程和原素材信息，保留可恢复版本与源素材关联。已有字幕先复用并核对，不重复识别；只有缺失或错配时才处理识别。需要内容剪辑或转写时按当前任务读取相应技能，不整套引入其其他处理步骤。
4. 通过当前可用应用工具读取界面再操作。历史按钮名称用于定位，不照抄事件中的坐标或 AX 元素编号。开拍与剪映无可用自动接口时，用可用的原生应用 UI 控制；不擅自改写未验证的草稿缓存格式。
5. 用户指定账号模板或专用预设时，读取用户提供的标准与交付边界，核对具体版本。关键模板或字体缺失时说明缺口，只暂停依赖它的样式处理，不凭名称猜测。不同账号与人物的字体、动画和交付要求分别处理。

## 统一字幕

### 先把文字与样式分开

- 按原声或已确认文案核对错字、专名、数字与断句；财税字幕重点保留主体、金额、时间和条件词。字幕校对不改变原声或论点。
- 中文口播需要新识别时，检查简体中文、语言检测、专名词库与每行字数。每行字数与专名词库依据当前账号和画幅设置，不套用其他项目。
- 区分普通字幕、重点花字、标题。先在普通字幕中选代表性短句和长句，设置一套基准：字体、字号、颜色、透明度、描边、位置、对齐及字／行间距；已有动画、双语结构按原任务保留。
- 优先复用已确认模板。缺字体或预设时先核对资源，不静默替换；存在关键差异时保留现状并说明。

### 再批量应用与检查

1. 先在样句中预览，核对人物脸部、手势和关键画面是否被挡，长句是否超出画面或安全区。
2. 在当前应用里确认“应用到所有字幕”或批量样式功能的实际覆盖范围。能够限定普通字幕时只作用于该层；若会连同重点花字与标题覆盖，先保留这些例外，再采用分组应用或逐段同步。
3. 应用后检查片头、片中、片尾、长句和重点词，回读字体、颜色、位置、描边等值。勾选按钮或看到一条正确字幕不能证明全片已统一。
4. 针对重点词恢复或保留原有高亮／花字，避免全部变成大标题。“应用到所有字幕高亮”与普通“应用到所有字幕”是不同范围，分别核查；只改普通字幕时不动高亮。新加重点只依据本条内容和参考风格。
5. 把本条实际使用的样式写入项目包装记录。只有用户明确要保存模板或更新长期标准时才修改共享预设；单条成片的调整留在本项目。

## 润色人物画面

- 在开拍的画面美化区域，按素材需要检查祛斑祛痘、磨皮、清晰度等项目；有原设置就先读取。一次改一项，用“按住对比”或前后预览比较，再播放人物转头、说话及手部运动段。
- 以自然肤质、五官不变形、边缘不闪烁为判断依据。参数按当前素材逐项比较，不套用固定数值。仅打开磨皮面板不等于已经使用磨皮。
- 效果需要模型下载时，等任务结束再核查画面；下载中或参数可见均不算渲染通过。卡住时保留工程，查明状态后再决定恢复，不持续重复触发。
- 描边、抠像、B-Roll 等只有本次要求或明确模板需要时才加。视频描边不是固定流程。

## 生成与设置封面

1. 以本条口播内容和已有标题为依据，确定封面文字；保留用户指定文字。先检查人物帧、比例、已有封面及目标平台安全区域，避免遮脸、截字或承诺超出正文。
2. 沿用当前指定路径。开拍流程为“设计作品封面”→检查模板与安全区→“AI封面”→生成。固定模板任务只替换指定局部，不借生成改掉布局、字体或其他锁定要素；指定开拍时不静默改用其他图像模型。
3. AI 封面会使用云端处理并可能消耗次数，按当前具体授权操作；已要求使用该功能时不重复确认。若与当前“仅本地处理”等明确限制冲突，只暂停云端步骤，继续其他包装。
4. 生成后检查候选中的人像、文字准确性、主题和安全区；已有可用候选先复用。仅在有具体缺陷需要改善时再生成，记录生成状态，避免无依据地连续点击。失败先查已有任务与结果，确认未完成后仅作一次有依据的重试；仍失败就报告并保留当前成果，不擅自购买次数或更换服务。
5. 每次生成／编辑封面均核查实际图片像素，包括仅在工程内应用的封面。默认以长边 2048 像素为目标并保持原图或指定比例；支持尺寸参数时设置，只有提示词入口时明确写入。查看可取得的实际文件／图像元数据；应用不提供时明确“尺寸未核验”。未达目标或比例不符时，及时说明实际值与工具限制，沟通处置并继续不受影响的工作，不把这部分标为达标完成。不裁切、拉伸或默默插值放大凑尺寸，不擅自改用其他模型、收费服务，也不把视频导出档位当作封面尺寸证明。
6. 用户让代选时选定符合本次要求的候选并执行“确定／应用”，返回工程核查封面缩略图或重新进入封面设置验证。只要求候选时交付候选并标注未应用；不要把“已生成”写成“已设为封面”。

## 一键包装与剪映交接（按需）

- 现有模板可用于起稿；若会重写已调好的字幕、标题或效果，先保留恢复点。“一键包装”不是每次必经步骤，进度 1%／2% 也不是完成；未完成时先查任务状态，避免连续提交。恢复不了就继续能完成的手动样式工作，并明确自动包装未完成。
- 只有本次交付需要时才导出并交接剪映。可通过开拍→MP4→剪映交接；MP4 中烧录的字幕与美化不会自动变成剪映可编辑图层，继续保留开拍工程。需要剪映可编辑字幕时优先使用已有独立字幕／工程数据，不在烧录字幕上再叠一套。
- 用户已指定工作台预览、剪映工程或直接成片时遵从对应边界，避免无必要地多建副本或打断用户当前工程。切换工程前核对素材名称和主题，避免把不同口播混为一条。

## 保存与交付核验

1. 保留当前项目的可编辑工程、源素材关系和包装记录；支持时保存后重开，检查样式与封面仍存在。应用的草稿缓存路径只是定位信息，不冒充可迁移工程包。
2. 有导出要求时，按源素材与本次交付约定设置比例、像素、帧率、格式和文件名。视频规格由源素材与交付要求确定；静态图片的 2048 长边规则也不等同于视频分辨率要求。
3. 等待导出完成，核对实际文件路径、大小、时长、宽高和帧率，再播放核对封面／片头、字幕代表段、画面处理段与片尾；本次未要求改音频时确认原声仍正常。只有预览或工程交付时，不额外导出一份视频。
4. 新项目使用用户指定的输出目录，可按 `<输出目录>/<账号或人物>/<日期>_口播包装/` 组织；已有项目继续原位置。需要记录本条样式与核验时，复制 [包装记录模板](assets/包装记录模板.md) 到项目工程目录，按实际状态填写，删去不适用字段。
5. 最终给可点击的工程／预览／封面／成片链接及简短状态：已做哪些、实际检查到哪一步、具体剩余项。分别表述封面候选生成、封面应用、工程保存、视频导出和播放核验；不把本地完成当成上传、发布或用户已批准。

## 调用示例

- `用口播视频包装处理这条视频，沿用已有模板，完成封面、画面润色和字幕统一。`
- `用口播视频包装，只统一普通字幕，原来的重点花字、封面和画面都保留。`
- `用口播视频包装，在开拍给这条视频生成封面候选，先不设置到视频里。`
