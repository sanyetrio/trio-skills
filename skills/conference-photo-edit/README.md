## 需要准备

- 能查看原图的 AI 助手，以及你有权使用的照片。
- 真正裁切、调色、局部修补和导出，需要你已选定的照片编辑工具与可用操作接口。
- 本包提供选片和精修流程，不包含照片、软件、账号或自动修图服务。只有文字查看能力时，不能完成照片筛选与精修。

## 安装与使用

1. 下载并保留完整的 `conference-photo-edit` 文件夹。
2. 将整个文件夹放到你所用 AI 客户端支持的技能目录，按客户端的方式重新加载技能。使用这一项不需要其他 Trio Skills 文件夹。
3. 在支持 `$技能名` 的客户端里，使用上面的请求；其他客户端可让它先读取本文件夹的 [SKILL.md](SKILL.md)，再处理你提供的照片。

只想选照片时直接说明“只选片”；需要精修时，说明使用哪套现有编辑工具、输出目录和尺寸。技能会分别记录选片、处理和导出状态，实际交付以成片文件为准。
