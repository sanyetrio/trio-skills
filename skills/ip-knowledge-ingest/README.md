# 把参考素材存成能查回的笔记

[单独下载这个技能](https://github.com/sanyetrio/trio-skills/raw/refs/heads/main/downloads/ip-knowledge-ingest.zip) · [安装方法](https://github.com/sanyetrio/trio-skills/blob/main/docs/%E5%9F%BA%E7%A1%80%E9%85%8D%E7%BD%AE%E4%B8%8E%E5%AE%89%E8%A3%85.md) · [返回用途导航](https://github.com/sanyetrio/trio-skills)

收集了一批作品、原文或拆片，想整理为一作品一笔记，方便以后查找和引用。

| 使用前提供 | 完成后得到 |
|---|---|
| 实际取得的作品原文、来源链接、已有拆片或附件；指定输出文件夹，写入 Obsidian 时提供目标 vault。 | 独立作品笔记、来源与分析的区分、索引，以及实际写入和缺失项目的回执。 |

## 直接这样说

> 用 $ip-knowledge-ingest 把这批参考作品整理成独立 Markdown 笔记，完整保留可用原文和来源，并建立索引。

## 安装与依赖

把本目录作为完整的 `ip-knowledge-ingest` 文件夹，放入你使用的 AI 客户端的技能目录，保留 `SKILL.md` 和所有随附资源；已有同名技能先比较，避免覆盖已有修改。在客户端重新加载技能后，发送上面的示例并附上实际材料。

基础输出只需要文件读写能力，不依赖其他技能或 Obsidian 插件；正式入库时需要可访问的目标文件夹。

## 使用范围

只保存实际取得的内容；没有拿到的原文或没有观看的画面会明确标为缺失。
