# 隔离教学输入

本例是为验证技能而自制的教学场景，不代表用户本人IP，不包含真实博主、热门数据、真实拆片观察或用户客户案例。

假设受众：保存了参考视频，却不知道写稿时怎样调用的内容创作者。
本题：说明保存时记下“解决什么问题、画面怎样搭配、原片位置”，并对照自己的拍摄条件。
假设资源：一人，手机固定支架，电脑录屏，空白纸；没有第二演员或外景。所有视频/录屏均尚未拍摄。
口吻：平稳、具体，先演示再解释。
授权：教学测试允许直接选题和生成分镜表，不拍摄、不联网、不生图、不配音、不渲染。
真实博主参考：0。T01为本次教学方法设计，不是外部观察。

脚本见script.json。普通口播正文为：

存一条参考视频，先记住它解决了什么问题。

再看这一句话，配了什么画面，在哪儿切换，把原片位置记下来。

最后对照自己的拍摄条件。能拍的留下，缺的素材列清楚，再写成自己的分镜。
