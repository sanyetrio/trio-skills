# 只安装这次需要的技能

## 先选一项

在[首页用途导航](../README.md)找到你这次要做的事，点“看说明”。每份说明都会写清楚：要提供什么材料、会得到什么结果、需要哪些软件或账号。

选好后点这一项的“ZIP”，在 GitHub 文件页点击下载按钮；也可以点该项中文说明顶部的“单独下载这个技能”直接下载。无需下载整个仓库。

## 把完整文件夹装进去

解压单项 ZIP，会得到一个以技能标识命名的文件夹，例如 `human-writing`。完整保留里面的 `SKILL.md`、参考资料、脚本和模板。

- Codex：放入自己的 `~/.codex/skills/`，再在新聊天确认是否识别。
- Claude Code：放入自己的 `~/.claude/skills/`，或当前项目的 `.claude/skills/`。参见 [Claude Code 官方技能文档](https://code.claude.com/docs/en/skills#choose-where-skills-load)。
- 其他支持 Agent Skills 的客户端：按它的说明导入完整文件夹。

已有同名技能时先比较、备份，保留自己的修改，不直接覆盖。

## 开始用

回到该项中文说明，复制该项说明里的示例请求给 AI，再提供实际材料。例如：

> 用 human-writing 把这段文案改得更顺口，保留原意，不编造案例。

安装技能只复制这些文件，不会自动安装编辑器、下载模型或连接账号。各项实际依赖写在自己的说明里。

## 单项和组合的区别

14项具体用途已各自携带必要参考文件，可以按需单独安装。`ip-content-sop` 是进阶组合调度，只在确实要串联多个步骤时使用，并另装涉及的功能技能。单独拆视频、写分镜或改文案不需要安装它。

## 可选基础配置

项目目录、输出目录、知识库等由使用者指定。想保留固定约定时，可把 [config.example.md](../config.example.md) 复制为 `config.local.md`，在任务中让AI读取；它不是自动生效的软件配置文件。账号和密钥在对应应用中配置。
