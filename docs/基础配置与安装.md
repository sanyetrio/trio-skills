# 基础配置与安装

## 下载

在 GitHub 页面选择 Code → Download ZIP，解压后保留目录结构；或使用 Git：

```bash
git clone https://github.com/sanyetrio/trio-skills.git
cd trio-skills
```

## 安装

每个 `skills/<技能标识>/` 都是一个技能目录，必须连同其中的 `SKILL.md`、`scripts`、`references`、`assets` 等实际存在的依赖一起保留。不要只复制正文。

- Codex：把需要的技能目录复制到自己的 `~/.codex/skills/`，再在新聊天中确认是否已识别。若已有同名技能，先比较并备份，不直接覆盖。
- Claude Code：复制到自己的 `~/.claude/skills/`，或当前项目的 `.claude/skills/`。是否支持具体工具与脚本，以当前客户端能力为准。目录规则参见 [Claude Code 官方技能文档](https://code.claude.com/docs/en/skills#choose-where-skills-load)。
- 其他支持 Agent Skills 的工具：按该工具说明导入完整文件夹；没有导入功能时，可在任务中指定阅读 `SKILL.md`。

七个 `ip-*` 技能有互相引用的交接规则，使用这一套时请把七个文件夹安装到同一个父目录。其他技能可单独选择。

安装是文件复制；不会自动安装 FFmpeg、Node.js、浏览器驱动，不会自动配置账号。先读各技能的依赖说明，再按实际任务准备环境。

## 配置

把根目录 `config.example.md` 复制为 `config.local.md`，填写自己的项目目录和可选知识库路径。在使用时明确让 AI 读取。该文件已被 `.gitignore` 排除。

这个仓库没有作者的 API Key、Cookie、登录状态、客户资料或私人知识库。需要云服务、飞书、生成模型时，由使用者使用自己的账号完成配置。

## 使用示例

- “用 human-writing 改写这段文案，保持核心意思，不补编经历和数据。”
- “用 ip-auto-storyboard 将这份稿子整理为分镜，原文不要改动。”
- “用 conference-photo-edit 处理我提供的会议照片，按这次给定的尺寸交付。”
- “用 anatomy 解释这套结构，交付可打开的交互图。”

最终能力取决于当前模型、客户端、输入材料和已安装工具。结构校验通过不能代替真实素材上的效果验收。
