## 怎么用

1. 选一个用途，打开它的中文说明。
2. 下载该项 ZIP，解压后把完整技能文件夹放进你的 AI 客户端技能目录。
3. 按该项说明准备材料，复制其中的示例请求给 AI。

[不会安装？看这份简短说明](docs/基础配置与安装.md) · [基础配置示例](config.example.md)

技能是任务指引和辅助资源。修图、剪辑、生成视频、操作网页等工作，仍需使用者自己的软件、模型或账号。
